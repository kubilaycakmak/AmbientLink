# AmbientLink 0.1.0 — first Windows alpha

Turn supported RGB bulbs into screen lighting from a Windows PC. This early
release runs locally and opens its controls in your browser. No account, cloud
API, Echo, Home Assistant or separate server is required.

## Download and run

1. Download **AmbientLink-0.1.0-windows-x64.zip** from the assets below.
2. Right-click the ZIP and choose **Extract All**.
3. Run **AmbientLink.exe** from the extracted folder. Python is included.
4. In the browser panel, choose **Find lights**, add your supported bulbs, and
   click **Start screen sync**.

Use the Windows ZIP, not the automatically generated Source code archives.
The package includes dependency licenses. The build is unsigned; Windows may
show an unknown-publisher warning. SHA256SUMS.txt covers the EXE and Windows ZIP.

[Full setup, calibration and troubleshooting guide](https://github.com/kubilaycakmak/AmbientLink/blob/v0.1.0/README.md)

## Included

- Govee H600B encrypted Bluetooth LE adapter, based on a live-tested transport.
- Experimental Govee LAN Control discovery and output.
- Dominant-color, average-color and left/center/right screen modes.
- Per-device region, power selection and visual color calibration.
- Manual color, brightness, smoothing, and fast fading for black scenes.
- Up to 60 FPS screen capture; independent output workers avoid stale frame queues.
- Local settings and local browser UI. No screen upload or telemetry.

## Alpha limitations

- Windows 10/11 x64 and the primary monitor only.
- BLE targets up to 30 output updates per second; LAN targets up to 10. Actual
  rates depend on hardware, radio conditions and scene changes.
- LAN output is unacknowledged and has not yet been physically validated.
- H600B Stop & restore attempts to restore the prior solid-color/power state;
  LAN devices retain their last output. Closing a browser tab leaves the app running.
- Other bulb models, keyboard/mouse/case RGB, HDR color management, multiple
  monitors and automatic startup are not supported yet.
- The standalone package has automated tests and an EXE launch/UI smoke check;
  it has not been validated across a broad range of PCs and bulb firmware.

Please report your exact device model, firmware, Windows version, transport and
visible error message in an issue. Remove personal device addresses before sharing.
