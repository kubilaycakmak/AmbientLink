# AmbientLink 0.1.1 — timing and live-control fixes

This alpha update fixes two causes of unstable lighting during setup and playback.

## Fixed

- Windows timer precision could let capture run above the selected FPS and send
  BLE updates faster than intended. Capture and device senders now recheck their
  monotonic deadlines; the event loop uses the high-resolution clock consistently.
- Changing a device's region or enabled state previously stopped, restored and
  reconnected every light. These settings now update the existing sessions.
- Repeated Start clicks no longer restart an active screen session. Switching
  between manual and screen colors retains device sessions and the original
  state used by the explicit Stop & restore action.
- Device controls now say **Turn on / Turn off**, making the action clearer.
  Status refreshes no longer recreate unchanged device dropdowns every second.

## Download and use

Download **AmbientLink-0.1.1-windows-x64.zip**, extract it, and run
**AmbientLink.exe**. Quit the previous version first. Device settings remain in
your Windows profile. Python is bundled; no Python installation is required.

[Usage and calibration guide](https://github.com/kubilaycakmak/AmbientLink/blob/v0.1.1/README.md)

This remains an unsigned Windows x64 alpha. H600B Bluetooth is supported;
Govee LAN is experimental and still needs physical validation. Other RGB
hardware, HDR management and multi-monitor selection are not included.

Nine automated tests pass, including regressions for early timer wakeups and
live device changes that must preserve other lights' connections.
